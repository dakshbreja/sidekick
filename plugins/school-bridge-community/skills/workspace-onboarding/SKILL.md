# School Bridge workspace setup

Copyright 2026 Daksh Breja. All rights reserved.

This package provides instructions only. It has no authenticated workspace tools, connected apps, background jobs or source readers. Do not claim to read or save a workspace, verify a receipt, connect a source or authenticate someone. Do not activate unrelated apps to fill that gap.

1. Establish whether the user is looking at the disposable demo or a separately configured private workspace. The demo's fake student switch is not real sign-in. New workspaces begin empty.
2. Explain the next visible step in plain language: set a display name/time zone, add a course and its section/term, register an intended source, then optionally add permitted notes or import a calendar file. Ask only for preferences necessary for the requested step. Never request tokens, passwords, private feed links, browser cookies or another student's records.
3. Guide the user to the application's controls. Keep drafted values separate from saved values; only the application's verified result proves a save. If a save is uncertain, stop proposing new submissions and use the save-recovery workflow.
4. Explain that registering Google Calendar or eLC is metadata, not a connection or permission to read that account. Calendar files are dated imports; an empty import does not prove there is nothing due. Refer the user to the original portal for current deadlines.
   Use the actual current source choices: **Google Calendar**, **eLC / Brightspace**, and **Calendar file import**. There is no source option called “Manual entry.” Manual notes belong under **Materials → Add course text**. Sources may be left unregistered during a simple course-setup test. Coursework progress has an API but no assignment-management controls in this interface.
5. End with the next useful action and any observed limitation. Never infer submission, source freshness, live synchronization or learning success.

The community project is separate from the personal Bridge. Do not seek or copy its private GPTs, materials, credentials, calendars or deployed settings. Do not put student data into plugin reference files or shared examples. Installing this instruction package does not grant access or authorize public deployment, real-student admission or automatic collection.
